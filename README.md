# 镜流 ContextFlow

面向桌面浏览器的 AIGC 创作画布。通过显式开启上下文承接，让独立图片或视频节点读取指定前序结果的文字与视觉信息，辅助当前内容生成。

## 在线交互演示

[打开镜流演示](https://haidarkhanuk3344-collab.github.io/contextflow/)

GitHub Pages 发布的是纯前端演示：免登录，可编辑画布、上传本地素材、切换风格及承接来源，体验示例结果、采用版本和下载流程。演示生成由浏览器绘制预设图形/动画，不调用 AI，也不执行真实视觉识别，不消耗模型额度。画布与上传素材只保存于当前浏览器 IndexedDB，清理浏览器数据会删除它们，不跨设备同步。

本地构建演示：`npm run build:demo`，随后 `npm run preview`。默认 `npm run build` 仍构建连接后端的正式前端。演示与正式数据相互隔离。

## 当前能力

- 项目画布、图片和视频节点、结果历史与下载。
- 个人图片素材库、分类管理与跨画布引用。
- 同类型节点的上下文承接，指定一个前序及其结果版本；普通素材参考独立控制。
- 图片视觉分析；视频末尾约 1–2 秒多帧分析，并将信息加入当前生成提示词。
- 古装真人、现代真人、中式二维、游戏 CG 四种风格预设。
- 邀请码登录、管理员初始化与登录。
- 火山图片/视觉接口、百炼单首帧图生视频接口。

上下文承接改善模型输入，不保证生成画面的像素或动作完全连续。当前是开发试用版本，并非已完成全部 PRD 的商用服务。文生视频、多参考视频模式、完整费用核算、任务中断后的自动恢复等仍需完善。

## 本地运行

需要 Node.js 22.23+ 和 npm。FFmpeg 由 `ffmpeg-static` 安装，首次安装需要联网。

```bash
npm ci
cp .env.example .env
```

在 `.env` 填入自己的服务端 API 密钥。模型是否可用取决于账号权限及服务商支持，生成会产生服务商费用。不要把密钥填到前端代码。

在 macOS/Linux 终端运行：

```bash
set -a
source .env
set +a
npm run dev:all
```

打开 http://127.0.0.1:5194 。后端运行在 127.0.0.1:5196。`.env` 需要按上述方式显式加载；单独运行 `npm run dev:all` 不会自动读取它。未配密钥时可以管理画布，相关生成能力不可用。

### 第一次设置管理员

后端首次启动会创建 `data/v1/admin-setup-token`。在自己电脑上打开这个文件，把其中的令牌接在下面地址末尾：

```text
http://127.0.0.1:5194/#/admin/setup/<令牌>
```

设置至少 10 位的个人管理员密码。此令牌不要分享或提交到仓库。后续使用页面中的管理员入口登录，登录后可生成邀请码。

没有默认管理员密码，仓库不包含作者的 API 密钥、邀请码、用户资料或素材。

## 数据和部署边界

项目、会话、任务和素材保存在本机 `data/v1/`，请备份整个目录。当前存储实现面向单进程，不能直接扩展为多个副本。

`npm run build` 仅构建前端，不会部署后端。GitHub Pages 无法运行本项目的 Node.js/FFmpeg 后端。对外部署需配置 HTTPS、反向代理、访问来源、持久存储，并完成权限隔离、限额及重启恢复验证。不要直接将开发服务器暴露到公网；当前费用记录不能视为真实账单或可靠硬预算。

## 验证

```bash
npm test
npm run build
npm run lint
```

测试使用模拟模型响应和自动生成的测试视频，不调用付费模型，也不依赖作者本机的验收素材。`server/service.mjs`、`src/contextLink.ts` 等由兼容性回归测试保留；正式启动入口是 `server/v1/start.mjs`，页面使用 `src/v1/`。
